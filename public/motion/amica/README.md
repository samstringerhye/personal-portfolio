# Amica homepage tour

- `home.webp`: the relaunched homepage, from the Figma file 03. Amica AEM System Documentation
  (Templates, Homepage – No Personalization, desktop), exported at 2x, cropped to the top 4420px
  (above the "Behind every claim" section, whose image is a placeholder) and scaled to 1440 wide.
- `home-overlay.webp`: the hero's nav text, quote card and pause button cut from `home.webp`
  (y 58 to 851), laid over the video.
- `anthem.mp4`: the homepage brand anthem from the Amica DAM, silent, 960 wide, H.264 CRF 27.
