## One system, organized for two build stacks

The existing library gave the project a foundation. I organized it into Foundations for shared rules, Components for reusable interface patterns, and Sections for patterns combined into larger page structures. Templates stayed distinct so teams could assemble pages without confusing page composition with source components.

I kept component names simple and used properties for type, size, state, layout, and media. That gave variations a place within each component family instead of turning every combination into another name to find.

I separated working files, published libraries, reference documentation, and client-share materials. I intended that structure to help design, implementation, and client review find the right source. I set the direction, delegated focused component and documentation work, and kept ownership of system structure and cross-file consistency.

The existing library and parallel AEM and React tracks shaped the approach. I clarified what the project already had and guided the parts that needed refinement for launch. The work extended an existing system rather than replacing it wholesale.
</ProseGroup>

## A quote-start choice shaped around the constraint

In a separate product-dropdown exploration, the “Wedding & Event” label clipped in the menu. I presented three options. Amica selected the option that widened the dropdown and narrowed the ZIP field, keeping the quote action inline. The team also confirmed that this layout should hold through the 1024px breakpoint rather than introduce another breakpoint. Amica approved the direction, and this was the option that shipped.

The choice balanced two visible needs in the same row: show the full product label and keep the quote action beside the ZIP field. I used the menu width to solve the clipped label, then gave up some width in the ZIP input to preserve that inline action. The documented breakpoint decision kept the team from solving the same layout with an extra responsive rule.

Amica’s in-house team took ownership of the broader Quote Start redesign. Our agency scope covered the visual reskin, not a functional redesign of the quote flow. I led the visual refinement of quote entry; I did not redesign the larger flow.
</ProseGroup>
