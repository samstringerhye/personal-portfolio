## The challenge.

The library behind the old site had no tokens. Color was hard-coded, dark mode meant a second copy of every component, and components were filed by page type. The rebuild had to happen without pausing a sprint.

</ProseGroup>

<ProseGroup>

## The approach.

Tokens name what you're painting, not where, so one button reads the right color on light and dark with no second copy. Each component carries its own states, sizes and rules, and the quote flow runs on the same parts, from the homepage ZIP code to the bundle summary.

</ProseGroup>

## The outcome.

Amica relaunched on the system on October 2, 2026, built to WCAG 2.1 AA, with a library and documentation for each platform: Adobe Experience Manager and React. A concept study before launch tested the direction with 500 people.

</ProseGroup>
