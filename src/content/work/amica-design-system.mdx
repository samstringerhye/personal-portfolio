## The challenge.

I joined four sprints into a rescue. The library was broken in ways no screenshot showed: no token system, components filed by page type, instances pointing at deleted masters. Indexing all 314,000 nodes found 3,044 flat references and 61 dead masters.

</ProseGroup>

## The approach.

</ProseGroup>

<ProseGroup>

### Two tiers of color.

Primitives sit hidden from pickers, and 54 semantic tokens name what you're painting, set for Light and Dark. Modes as variables let one component carry both, so Icon Button dropped from 80 variants to 60.

</ProseGroup>
