## The challenge.

The old library had no tokens. Color was hard-coded, dark mode meant a second copy of every component, and the rebuild couldn't pause a sprint.

</ProseGroup>

<ProseGroup>

## The approach.

Tokens name what you paint, not where, so one button works on light and dark. The quote flow runs on the same parts, start to finish.

</ProseGroup>

## The outcome.

Amica relaunched on the system in October 2026, built to WCAG 2.1 AA, on Adobe Experience Manager and React.
