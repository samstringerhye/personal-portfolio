## Building the components as well as the pages

I created the design-system file and built reusable buttons, cards, navigation items, and controls, along with shared type and color styles. This made the visual designs available as parts the team could use across templates. My contribution covered both the page compositions and the reusable interface elements within them.

The system work formed part of a global collaboration. Samsung supplied the core visual foundations, and Duotone’s team in Korea managed the linked library across design files. I built and organized components within that framework, connecting my page work to the shared system.
</ProseGroup>

<ProseGroup>
## Shaping the experience together

The navigation, page templates, and components developed together through the team’s design work, usability findings, and developer input. My contribution spanned the page compositions and the interface details, including imagery placement, hierarchy, type spacing, and reusable components.

I handed the final visual designs to Samsung’s development team in 2021.
</ProseGroup>
