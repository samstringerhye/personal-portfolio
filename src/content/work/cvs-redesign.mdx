<p class="cs-intro">I led the design system behind CVS.com's shop redesign: one type scale, one icon grid and a component library for home, category, brand and product pages, built by five designers in three months.</p>

</ProseGroup>

<ProseGroup>

## The challenge.

CVS is both a pharmacy and a general retailer, and its shop grew through acquisitions: fractured type scales, inconsistent icons, components built one by one. The site was live with real customer volume, so nothing could start over.

</ProseGroup>

<ProseGroup>

## The approach.

</ProseGroup>

<ProseGroup>

### Type and icons first.

I started with the parts every page shares: one rational type scale, and every icon and illustration drawn on one grid in CVS red, so a 16px icon and a 48px icon read as one family.

</ProseGroup>

### Desktop and mobile at once.

Every component was designed for both sizes from the start, not desktop first and adapted after.

</ProseGroup>

### Pages from shared parts.

Home, category, brand and product pages are assembled from one library of composable parts, not built from page-specific components.

</ProseGroup>

## The outcome.

In three months the team delivered one type scale, one icon grid and a component library, so new pages are assembled from shared parts instead of built one component at a time.

</ProseGroup>
