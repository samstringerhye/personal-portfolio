# Conventions

Copy and working rules are in AGENTS.md above. Its "Project Overview" and "Content Conventions"
sections predate the build; trust the code where they disagree. See README.md for layout and deploy.

## Commands

- `npm run dev` (port 4321), `npm run build`, `npx astro check`, `npm run preview`.
- Run `npx astro check` and `npm run build` before finishing code changes. Check is at 0 errors;
  keep it there (hints are expected).
- Do not run `npm run deploy` or `wrangler deploy` unless Sam asks.

## Data and content

- `src/data/tokens.json` is read by path from another repo (the hub's `design/build_css.py`).
  Do not move, rename or restructure it, or other files in `src/data/`, without checking that
  consumer. Edit token values there; `tokens.schema.json` and `tokens.ts` describe it.
- Animation constants live in `src/data/animation.config.json` (documented in
  `animation.config.docs.md`). Keep the docs table in sync when changing values; do not inline
  literals in components.
- Case studies are MDX in `src/content/work/`, validated by `src/content.config.ts`. Images come
  from `src/assets/work/<slug>/`. The card art is generated by `scripts/thumbnails/`.
- Password-protected case studies use `passwordProtected: true`, `WAB_PASSWORD`, and
  `src/middleware.ts`. Embedded prototypes live in `public/_protected-embeds/` and are served
  through the middleware, not directly.
- Site copy and facts must be accurate: real metrics or none. Client work shown here is
  limited to what the site already publishes.

## Style

- Plain CSS with tokens; `prefers-reduced-motion` must be respected for all motion.
- Match existing comment density: short comments only where the reason is not obvious.

## Do not commit

- `.env*` (except `.env.example`), tokens or Cloudflare ids, `dist/`, `.astro/`, `.wrangler/`,
  `node_modules/`, `test-results/`, `.playwright-mcp/`, `.DS_Store`, logs.
- Debug screenshots (`*.png` is ignored outside `src/` and `public/`), trial fonts, and
  `inputs/`, `output/`, `videos/` working folders (all gitignored).
- Local absolute paths or private notes in docs: this repo is public.

## Gotchas

- `.agents/skills` and `.claude/skills` are tracked despite `.gitignore` entries (added earlier);
  leave them alone.
- `WorkCarousel.astro` and `BioSection.astro` are unused (see `docs/notes/session-log.md`).
- Large source images are already in history. Compress before adding more.
